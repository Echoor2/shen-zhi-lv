# 身姿律 · 音随意动

中国好创意大赛 · 数智音舞创新专项赛参赛作品开发原型。

> 让身体成为乐器，让动作成为旋律。

## 项目简介

《身姿律》是一个在浏览器中运行的互动数字艺术作品。参与者面对电脑摄像头自然移动身体，系统实时识别姿态，并将动作映射为合成声音与 Canvas 视觉反馈。

当前版本如实采用**人体动作捕捉与实时参数映射**生成音乐；不包含 AI 实时作曲、后端、数据库或用户账户系统。

## 核心创意

身体与手部动作经过平滑分析后进入两条并行输出：

```text
摄像头 -> MediaPipe Pose -> 身体动作特征 ----\
                                               -> 连续音乐合成
摄像头 -> MediaPipe Hand Landmarker -> 手指特征 -/
                                               -> 粒子 / 光环 / 骨架 / 声波
```

动作到连续音乐的基础映射：

- 上半身质量评分：双肩、肘、腕可见即可持续互动，髋部只作可选增强；质量达到 `0.4` 即允许音乐继续。
- 左手高度：量化到五声音阶，决定主旋律音区；右手高度参与辅旋律与合法和声音程。
- 手腕速度：控制旋律密度与音符时值，不直接决定音高。
- 手部运动方向：控制旋律上行或下行；相邻音符保持 1–2 个音阶级数的惯性。
- 双臂展开与动作幅度：控制整体响度、Pad 层级与和声丰富度。
- 身体左右位置：平滑控制声像 `Pan`，限制在 `-0.65 ~ +0.65`。
- 肩线旋转：在下一小节选择安全和声进行，绝不逐帧切换和弦。
- 动作速度（`movementSpeed`）驱动 BPM，手腕移动速度是主要因素，身体移动与整体动作能量作辅助修正；目标范围约为 60–105 BPM，并平滑变化。
- 加速度：产生受冷却保护的合成重音与视觉能量爆发。
- 动作速度同时影响音符密度；动作幅度影响音量与和声丰富度。手部位置影响音高与声像，手指和手势可产生受约束的装饰音、滑动音或特殊和声。
- 用户基本停止动作后，音乐逐渐衰减至接近静音；动作恢复后，音乐重新响应。
- Pose 暂时丢失：进入最长 1.2 秒的 Grace Period，随后降低复杂度并保留低音 Pad。
- 手掌张开：补充和声层数；双手同时张开可扩展当前和声，而双手收拢会使音乐自然收束。
- 拇指与食指距离：平滑控制音色明亮度；中指速度增加受预算限制的装饰音密度。
- 食指高度：只在当前主旋律附近做最多两个五声音级的细节偏移；食指上下扫动会添加同调式装饰音。无名指伸展延长连音，小指控制高频装饰与立体声宽度。
- 手指捏合：在当前旋律或当前手高量化出的合法五声音阶位置上点奏。手指层不创建新的音乐时钟，也不会覆盖手臂控制的主旋律。

默认使用 C 大调五声音阶 `C D E G A`，覆盖多个八度，避免随机半音造成不协调听感。当前音乐规则是确定性的动作参数映射，不宣称使用 AI 实时作曲。

## 技术栈

- HTML5 / CSS3 / 原生 ES Modules
- [MediaPipe Tasks Vision PoseLandmarker](https://ai.google.dev/edge/mediapipe/solutions/vision/pose_landmarker/web_js)
- [MediaPipe Tasks Vision HandLandmarker](https://ai.google.dev/edge/mediapipe/solutions/vision/hand_landmarker/web_js)
- Web Audio API：`OscillatorNode`、`GainNode`、`BiquadFilterNode`、`StereoPannerNode`
- Canvas 2D

姿态与手部识别均使用官方 `@mediapipe/tasks-vision@0.10.14` 的 `vision_bundle.mjs` ES Module。为避免展演现场或内置浏览器拦截第三方 CDN，固定版本的浏览器模块、WASM 和官方 `.task` 模型已随项目放在 `assets/vendor/mediapipe/` 与 `assets/models/`；运行时不会再向 jsDelivr 或 unpkg 请求这些依赖。Pose 与 Hand 都优先使用 GPU，失败后回退 CPU。核心项目没有构建步骤、后端或数据库依赖。

手部层是 V4 的增强能力：每个 GPU / CPU 初始化尝试都有约 9 秒超时，应用层另有约 12 秒的总启动截止时间。手模型加载或单帧推理失败时，系统会保留 V3 的 Pose、连续音乐、音频与视觉，不会因此停止演奏；右上角显示 `HAND DETAIL UNAVAILABLE · BODY MUSIC CONTINUES`，而不是无限停在加载中。

## 本地运行

由于摄像头通常只允许在 `localhost` 或 HTTPS 页面中访问，请不要直接双击打开 HTML 文件。

在项目目录运行任意静态服务器，例如：

```bash
npx serve .
```

然后打开命令行显示的 `http://localhost:3000`（实际端口以输出为准）。也可以使用 VS Code Live Server、Python `http.server` 或其他本地静态服务器。

1. 打开页面，点击 `START`。
2. 在浏览器弹窗中允许摄像头。
3. 站在画面中央，移动手臂或上身。
4. 观察骨架、光环、粒子和声波，并聆听由动作触发的合成声音。

## 浏览器与权限

建议使用桌面版 Chrome、Edge 或 Safari 的较新版本。需要：

- 可用摄像头
- `getUserMedia` 权限
- Web Audio API
- 可通过本地静态服务器访问项目资源

拒绝摄像头权限、浏览器不支持摄像头、姿态模块加载失败或音频不可用时，页面会显示非技术性的系统状态提示。

## 当前已实现

- 全屏沉浸式数字艺术舞台、开场与 START / STOP 状态。
- 摄像头画面与 Canvas 同步叠加。
- MediaPipe 单人 PoseLandmarker 实时检测。
- V4 手部与手指捕捉：HandLandmarker 最多识别双手各 21 个关键点，并通过 Pose 手腕位置优先完成左右手空间关联。
- V4 手指状态与手势：EMA 平滑、手部短暂丢失宽限、Pinch 迟滞与冷却、Open / Close 去抖、食指上下 Swipe。
- 发光人体节点、骨架、能量核心、动作定向粒子、声波扩散。
- 发光的双手 21 点骨架叠加，手指点奏、主旋律与重音都会同步产生视觉波纹。
- 上半身优先的动作分析、关键点指数平滑、身体可用性评分、意图检测和 1.2 秒 Pose 丢失宽限。
- V3 连续音乐引擎：`MotionMusicMapper`、`MelodyGenerator`、`HarmonyGenerator`、`RhythmGenerator` 与 `PhrasePlanner` 分层协作。
- 内部八分音符时钟、16 音符旋律记忆、手势量化、持续 Pad、主旋律、辅旋律、和声和合成节奏层。
- 和弦只在 4/4 小节边界更新；8 小节短语会在 BUILDING / PEAK / RELEASE / REST 间自然转换。
- 使用 `AudioContext.currentTime` 提前调度的 ADSR 合成器、主音量控制和低通滤波。
- 三种模式的可切换架构与视觉主题：五声古韵、电子律动、自然声境。
- `MOTION`、`TEMPO`、`ENERGY` 参数显示。
- `P` / `ESC` 展示模式，`1` / `2` / `3` 模式快捷键，`SPACE` 启停，`D` 跟踪调试层。

## V4 手指测试方式

V4 保持 V3 的连续音乐架构：身体决定节奏、能量与和声结构，手臂决定主旋律，手掌控制和声与音色，手指仅添加可控的微观细节。

1. 点击 `START` 并允许摄像头，在手部进入镜头后按 `D`，确认 `HANDS` 出现 `L+` 或 `R+`。
2. 保持身体与手臂轻微运动，确认没有手指动作时 Pad、主旋律与节奏仍能持续。
3. 食指与拇指捏合，确认出现单次、受五声音阶约束的点奏，不会持续爆音。
4. 快速活动中指，确认主旋律附近出现少量装饰音；停止后应回到原有主旋律。
5. 伸展无名指，确认音符更连贯、更长；伸展小指，确认空间感与高音装饰轻微增加。
6. 张开一只或双手，确认和声层更丰富；双手同时收拢约 300ms，确认音乐自然收束。
7. 让一只手短暂离开画面后再回来，确认 V3 主音乐不停止，手部细节在最多约 620ms 的宽限后平滑恢复。

项目也包含不需要摄像头的 V4 回归脚本：

```bash
node work/verify-v4.mjs
```

该脚本覆盖左右手与单手关联、手部丢失宽限、Pinch / Open / Close / Swipe、手指参数映射、五声音阶约束、装饰音与重音预算，以及 V3 连续时钟在无手部输入时的持续性。它不替代真人摄像头与实际扬声器试听。

## V3 测试方式

1. 启动本地静态服务器并点击 `START`。
2. 只让肩膀、手肘和手腕进入画面，按 `D`，确认 `QUALITY` 达到 `0.40` 以上。
3. 缓慢上抬左手，确认旋律按五声音阶逐步上行；缓慢下落时逐步下行。
4. 加快挥手，确认旋律更密、音符更短，但不产生逐帧爆音。
5. 大幅展开双臂，确认和声和 Pad 更饱满；轻微动作时保持克制。
6. 停止动作 3 秒，确认 Pad 仍在，旋律变稀疏而非突然消失。
7. 连续挥动一只手 30 秒，确认旋律持续推进，不会每 1–2 秒重新开始。
8. 短暂离开画面约 0.5–1 秒后回来，确认音乐经过宽限自然恢复。

项目也包含不需要摄像头的回归脚本：

```bash
node work/verify-v3.mjs
```

该脚本覆盖上/下行旋律、单手追踪、Pose 宽限、静止呼吸层、和弦小节边界，以及 30 / 60 / 120 秒的连续调度。
